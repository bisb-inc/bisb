# Backend

Diretório reservado à API REST do Competitive Monitor. A linguagem, o framework e o banco ainda serão definidos em [tech-stack.md](../.ai/tech-stack.md).

Responsabilidades previstas:

- Gerenciar análises, empresas e seus vínculos.
- Persistir `Analysis`, `Company`, `AnalysisCompany` e `Event`.
- Orquestrar a coleta por empresa.
- Integrar providers de notícias e X/mock.
- Normalizar resultados e disponibilizar eventos para a timeline.

Consulte os [endpoints e o modelo inicial](../docs/arquitetura.md). As instruções de instalação, configuração, execução e testes serão adicionadas com a implementação.
