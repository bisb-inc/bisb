# Prompt de geração de contexto

Use o texto abaixo ao revisar ou atualizar o contexto do projeto:

```text
Leia competitive_monitor_mvp.md, README.md, docs/arquitetura.md e os arquivos de .ai/.

Consolide o contexto do Competitive Monitor considerando:
- O objetivo e o escopo do MVP.
- A separação entre frontend, backend, persistência e providers.
- As entidades e os endpoints propostos.
- A alternativa de dados mockados para o X.
- As decisões técnicas confirmadas e as questões ainda pendentes.

Atualize os documentos de contexto afetados, mantendo consistência com a proposta.
Não apresente escolhas pendentes como decisões tomadas nem funcionalidades futuras como parte do MVP.
Ao finalizar, resuma as alterações e as decisões que ainda precisam ser definidas pelo grupo.
```
