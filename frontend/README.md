# Frontend

Diretório reservado à interface do Competitive Monitor. A stack ainda será definida em [tech-stack.md](../.ai/tech-stack.md).

Fluxo previsto:

1. Listar e criar análises.
2. Cadastrar empresa-alvo e concorrentes.
3. Executar a coleta.
4. Visualizar acontecimentos na timeline comparativa.
5. Aplicar filtros por empresa, fonte e período.

A interface deverá contemplar carregamento, ausência de resultados e erros de coleta. As instruções de instalação, configuração, execução e testes serão adicionadas com a implementação.
